# Tavern MiniMax TTS

适用于 SillyTavern（ST）和 TauriTavern（TT）的 MiniMax 配音扩展，支持多角色音色、情绪配音、语音收藏及语音 / VRM 视频通话。

## 安装

在酒馆的 **扩展管理 → 安装扩展** 中填写：

```text
https://github.com/yanhyhuan/tavern-minimax-tts.git
```

安装后重新加载页面，在顶部 **扩展 → MINIMAX TTS** 中配置插件；从魔棒菜单打开 **MINIMAX TTS** 可选择消息和语音操作。ST 和 TT 使用同一个地址，安装扩展即可使用，无需额外安装服务端插件。

日后通过扩展管理器更新。使用旧仓库的用户，请先在「语音收藏」中备份导出，再卸载旧扩展并用上述地址重新安装。

## 使用

### 首次配置

1. 打开顶部 **扩展 → MINIMAX TTS → TTS配置**，填写 MiniMax **API Key**，选择账号对应的 **API 节点**。
2. 选择默认模型和默认语音；**Group ID** 按账号要求填写，不需要时留空。
3. 点击 **测试语音**，听到声音后即可开始使用。测试会实际合成语音，消耗 MiniMax 额度。

### 聊天配音与角色音色

- 从魔棒菜单打开 **MINIMAX TTS**，弹窗默认选中最近的角色消息，也可以切换历史消息。点击 **生成** 合成语音、**播放** 收听、**重试** 重新生成，或 **编辑** 调整参数和版本；播放时可点击 **停止**。
- 开启 **语音气泡** 后，也可以单独播放某一段。
- 开启 **自动播放**，新回复会自动配音。
- 在 **语音库** 中添加音色，在 **角色绑定** 中为当前角色、用户或其他说话人指定音色。
- 在 **格式化** 中设置正则规则，可选择只朗读台词，过滤旁白或其他不想朗读的内容。

### AI 情绪配音（可选）

1. 在 **LLM预设** 中填写副模型的接口格式、API 地址、密钥和模型，测试通过后保存预设。
2. 在 **格式化** 中开启 **启用格式化**，选择该 LLM 预设和 **内置·专业AI配音导演（推荐）** 模板。
3. 按需开启 **自动情绪导演**，调整上下文条数和角色声音人格。

副模型会分析说话人、情绪、语速和停顿。导演提示词已经内置，无需添加到角色卡或世界书。启用副模型格式化后，正则提取规则不再生效。副模型与 MiniMax 分别消耗各自的 API 额度；基础配音只需要 MiniMax。

### 收藏与备份

点击语音旁的 **☆** 收藏。在 **语音收藏** 中可以搜索、试听、连续播放、修改标题 / 标签 / 备注，以及删除收藏。

**备份导出** 会保存包含音频的备份文件；**恢复备份** 会将收藏追加到现有列表。普通音频缓存清理不会删除收藏。

### 语音与 VRM 视频通话

1. 先在 **LLM预设** 中配置可用的副模型。
2. 在 **语音通话** 中选择预设并开启通话，点击悬浮球开始，按系统提示允许麦克风权限。
3. 使用视频通话时，在 **视频通话** 中选择预设，上传 `.vrm` 模型或填写模型 URL，预览后开启视频通话。

通话需要客户端支持麦克风和语音识别；视频通话还需要支持 WebGL。手机可先将渲染质量设为 **1×**。

### 跨设备使用

- **TT**：在宿主中启用完整同步，设置、MiniMax 与副模型 API Key、提示词、角色音色绑定、收藏、音频缓存和上传的 VRM 模型都会随宿主数据同步。接收完成后重新加载页面。
- **ST**：其他设备访问同一台酒馆并登录同一账号，即可使用该账号的设置、Key、收藏和上传模型。

遇到收藏或缓存读写问题，可在 **TTS配置 → 运行插件诊断** 中检查；诊断不会调用付费语音合成。
