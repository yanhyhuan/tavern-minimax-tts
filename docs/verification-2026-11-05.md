# 单次安装与宿主同步验证（2026-11-05）

## 实现

- ST 使用内置 Files API 保存当前账号的收藏、缓存和模型，副模型和流式通话使用内置 Chat Completions API。
- MiniMax 使用允许跨域的官方接口，完整传递情绪、语速、音量、音调、语言和 Group ID；保留瞬时失败重试。
- TT 继续使用原生扩展存储；上传模型从浏览器 IndexedDB / 临时 Blob URL 改为可同步的文件引用。
- Key 和其他设置仍保存在宿主的扩展设置中。未修改宿主同步目标、周期或用户选择的范围。
- 旧浏览器和旧服务端收藏复制迁移，逐条提交并按来源 ID 去重；中断可重试，保留原数据。迁移保留旧服务端支持的长文本和备注。

## 已生成语音的气泡漏显修复

- 复现：已有生成记录后勾选气泡，两段普通台词只显示第一个气泡；正文含 `class` 属性的 HTML 消息完全没有气泡。
- 原因：气泡注入和缓存状态判断把非零 `pauseMs` 当作纯停顿项；注入函数又把带 HTML `class` 属性的角色消息整体跳过。按是否有台词文本判断可播放段落，保留原数组下标；已有生成记录可正常显示 HTML 消息的气泡。魔法棒消息列表同步取消 `class` 属性过滤。
- 检查所有 `pauseMs` 判断，仅修正气泡过滤与缓存状态；播放前的停顿逻辑保留。纯停顿和空白段落不生成气泡。增加 2 项回归测试，现共 19 项测试通过。
- 在真实 ST 页面用模拟音频验证 9 项流程：勾选后恢复已有气泡、不重复合成、带停顿台词的缓存与索引、HTML 台词、Markdown 未匹配时的底部气泡条、开关反复切换、第二段播放与收藏、宿主重绘后恢复及魔法棒选择 HTML 消息。页面无脚本错误，未使用付费 API；未在用户的真实 TT 页面验收。
