# 用户台词、语音气泡和播放控制验证（2026-11-07）

## 问题与处理

- 截图中的用户台词属于角色回复中的一段对白，已确认在语音编辑器的段落列表中也缺失。副模型格式化之前只传入主要角色信息；使用自定义模板且关闭情绪导演时，不会明确提供当前用户名称和 persona。重试原先还会复用同一份导演缓存。现为副模型提供用户身份和完整提取当前对白的要求，强制重试时重新调用副模型，并根据实际提示词及身份区分缓存。
- 正文底部兜底条会重复显示部分语音且容易误触。气泡改为只插入能定位到正文的位置，支持跨 HTML 文本节点匹配并避免相互重叠的片段重复插入；无法定位的片段不再生成底部语音条，仍可通过魔法棒播放整条消息。
- 正文喇叭使用独立按钮，播放中再次点击可停止；气泡与魔法棒使用同一播放器，加载中取消或切换后迟到的音频不会继续播放。

## 自动检查

`npm run check`、`npm test` 和 `git diff --check` 通过；共 32 项 Node 测试。对气泡匹配另以 Chromium 执行 7 组 DOM 检查，覆盖跨节点和空格、重复及重叠片段、原始索引、无底部条、宿主重绘、开关清理和未匹配时不重复注入。

## 隔离 ST 浏览器验证

在隔离 SillyTavern 1.19.0 实例中使用 Chromium 和模拟接口完成以下验证：

- 用户和其他角色的模拟对白均出现在编辑器中，分别使用绑定音色；发送给副模型的请求包含用户身份及 persona，历史上下文不包含所选消息之后的内容；重试产生第二次副模型请求。
- 含粗体的跨节点台词保留原有文字及 HTML，重复和重叠片段不产生底部语音条；开关切换、宿主重绘恢复气泡，未匹配正文不会每秒重建。
- 只有喇叭按钮触发播放，再点停止；切换段落及魔法棒播放互斥；魔法棒可停止气泡；加载期间取消、切换后迟到的请求不会播放；播放期间重绘后停止按钮状态正确；自然结束恢复状态。
- 模拟同一段音频同时触发媒体错误和播放拒绝时，播放队列只前进一次。
- 在 390px 视口下，正文中的播放与收藏按钮可见、位于视口内且不重叠。

浏览器共完成 12 项流程检查，页面脚本错误为 0；合成请求 6 次、副模型请求 2 次，均由测试拦截为模拟响应，未调用真实付费接口。当前代码已与隔离实例内的 `index.js` 和 `style.css` 按 SHA-256 校验一致。

## 验证边界

未在用户实际使用的 TauriTavern 页面、真实 MiniMax 或真实副模型上验收。模拟副模型按预设返回两句对白，只验证请求内容、保存、音色绑定和播放链路；真实模型仍可能受到其能力、提示词和预处理规则影响而漏提取，需要在实际聊天中重新点击“重试”验证。
